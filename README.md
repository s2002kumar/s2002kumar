Next.js, FastAPI, PostGIS, shortest-path algorithms; [Waterloo pilot](https://51.222.36.79) and [recorded demo](https://github.com/s2002kumar/pathable/blob/main/docs/evidence/media/pathable-ux04-demo.webm). Deterministic routing, not ML.

Includes bounded, evidence-citing **AI analysis**; the [recorded GitHub demo](https://github.com/s2002kumar/DataProof/blob/main/docs/media/live-demo.mp4) uses deterministic checks and rule-based diagnosis. Live-model value has not yet been established.

[Five-minute case study](https://github.com/s2002kumar/crashcourt/blob/main/docs/ENGINEERING_CASE_STUDY.md).
- **[Prepay](https://github.com/s2002kumar/PrePay)** — Mortgage cash-flow modeling with **LightGBM / competing-risk models**, point-in-time data pipelines, temporal evaluation, and a finance engine. [Synthetic-data demo](https://s2002kumar.github.io/PrePay/); real-world forecasting accuracy is not established.
